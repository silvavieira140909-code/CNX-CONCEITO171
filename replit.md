# Vault Prime

## Executar no Replit

- O workflow `Start application` executa `npm run dev` na porta 5000.
- O build de produção pode ser validado com `npm run build`.
- As funcionalidades de autenticação e armazenamento privado precisam de `VITE_SUPABASE_URL` e `VITE_SUPABASE_ANON_KEY` configuradas no ambiente.
- O projeto mantém sua estrutura React + Vite + TypeScript original e usa os arquivos de entrada na raiz.
